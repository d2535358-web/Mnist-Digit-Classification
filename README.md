Project Description
Handwritten digit recognition is an important application of Machine Learning and Deep Learning.
This project uses the MNIST Handwritten Digit Dataset to train a neural network that can recognize handwritten digits from 0 to 9.
Each image in the dataset is a 28 × 28 grayscale image. The model learns the patterns in the images and predicts the correct digit.
Objectives
Recognize handwritten digits from 0 to 9.
Use the MNIST dataset for Deep Learning.
Preprocess and normalize image data.
Build a neural network using TensorFlow and Keras.
Train and evaluate the model.
Visualize training accuracy and loss.
Predict handwritten digits.
Dataset
The project uses the MNIST Handwritten Digit Dataset.

Training images: 60,000

Number of classes: 10

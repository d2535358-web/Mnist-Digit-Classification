## 📌 About the Project

MNIST Digit Classification is a Deep Learning project that identifies handwritten digits from **0 to 9**.

The project uses the **MNIST Handwritten Digit Dataset**. Each image is a 28 × 28 grayscale image. A neural network is trained using these images to recognize and classify handwritten digits.

Click the button above to open the project directly in Google Colab.

---

## 🎯 Objective

The objective of this project is to build a Deep Learning model that can recognize and classify handwritten digits using the MNIST dataset.

---

## 📊 Dataset

The MNIST dataset contains handwritten digits from **0 to 9**.

| Feature | Details |
|---|---|
| Training Images | 60,000 |
| Testing Images | 10,000 |
| Image Size | 28 × 28 pixels |
| Image Type | Grayscale |
| Number of Classes | 10 |
| Classes | 0–9 |

---

## 🧠 Model Architecture

The project uses an Artificial Neural Network built using TensorFlow and Keras.

### Layers Used

1. Input Layer
2. Flatten Layer
3. Dense Layer – 128 neurons
4. Output Layer – 10 neurons

### Activation Functions

- **ReLU** – used in the hidden layer
- **Softmax** – used in the output layer
